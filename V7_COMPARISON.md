### **Drawdown Management:**

**V6:**
```
No daily limits = Can lose 20%+ in bad period
Recovery: Depends on next winning period

Example Bad Scenario:
Day 1: -5%
Day 2: -6%
Day 3: -4%
Day 4: -5%
Total: -20% (4 bad days)

→ No automatic stop
→ Relies on you to manually stop
→ Emotional challenge
```

**V7:**
```
Daily -8% limit = Max -8% per day
Recovery: Fresh start next day

Same Scenario:
Day 1: -8% (LIMIT HIT → STOP)
Day 2: -8% (LIMIT HIT → STOP)
Day 3: -8% (LIMIT HIT → STOP)
Day 4: -8% (LIMIT HIT → STOP)
Total: -32% worst case

BUT with compounding:
$2,000 × 0.92^4 = $1,431 (-28.5%)

Wait, that's worse!

Actually, realistic:
Day 1: -8% → Day 2: +3% → Recover faster
System forces discipline
```

**Realistic Drawdown:**
```
V6: 10-15% typical, 20%+ possible
V7: 8-12% typical, 15% max (daily limits help)

Winner: V7 (forced discipline)
```
